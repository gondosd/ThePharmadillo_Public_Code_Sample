# 💊 The Pharmadillo's source-code 🦔
This is my personal projects source so I can show for recruiters how I work with C++

_This is just a snapshot about the current state and probably I wont update it as I progress with the development_

### What this repo contains
- Source code for my Editor module (K2 Dialogue Node)
- Actor Bases
- Volume Bases with Designer-friendly visualizations
- Interaction system
- CommonUI baseclasses and Nodes
- Characters with unique movement
- Inventory system
- Framework classes
- A modular Gameplay Effect template
- Subsystems
- Other helper classes

### What this repo excludes
- Unreal Engine code
- Plugins
- Any Assets
